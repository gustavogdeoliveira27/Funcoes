# Funções
Exercícios de funções propostos na matéria de Raciocínio Algorítmico na faculdade PUCPR.
Os exercícios utilizam a linguagem de programação Python e foram desenvolvidos no leitor de código-fonte VS Code. Alguns exercícios possuem múltiplos argumentos posicionais (*args) e argumentos nomeados (**kwargs). Utilizam também funções com Lambda, recursivas, Docstrings, max(), items(), maps(), filter(), list(), len(), raise Value Error, help(), entre outros.
